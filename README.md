# exp5

Flutter experiment 5 - a budget calculator app for tracking expenses against a budget.

## Use

```
flutter pub add exp5
```

```dart
import 'package:exp5/exp5.dart';

runApp(const BudgetApp());
```


## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Open a terminal and run:
   flutter pub get
3. Pick a device (Android phone, emulator, Chrome) from the bottom-right corner.
4. Press F5 or run: flutter run
